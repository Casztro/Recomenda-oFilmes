# Recomenda-oFilmes

Um site simples onde partilho recomendações de filmes do meu interesse.

## Sobre o projeto

O Recomenda-oFilmes é um projeto pessoal criado para reunir e apresentar filmes que considero interessantes. A proposta é partilhar sugestões de filmes a partir das minhas próprias preferências.

## Estado

Projeto pessoal.
